# PropIntel — ידע לקוחות

> **מצב:** ריק בכוונה. עדיין אין משתמשים משלמים/בטא אמיתיים לתעד. **אל תמלא את הקובץ הזה בניחושים** — סוכן שרואה אותו ריק צריך לדעת שזו עובדה על שלב המוצר, לא כשל.

כשיהיו משתמשי בטא/לקוחות ראשונים, כאן ייכנס:
- פרסונות שמאים אמיתיות (סוג עיסוק, גודל משרד, כלים מתחרים בשימוש היום)
- התנגדויות/חסמי אימוץ אמיתיים שנאספו
- בקשות פיצ'רים חוזרות
- ציטוטים ודוגמאות אמיתיות (לא מומצאות)

**סוכן מוצר עתידי** ייפתח את השלב הזה כשיהיה דאטה אמיתי למלא.
