# Audio Transcribe — תמלול גנרי של אודיו/וידאו

## 📋 סקירה
סקיל שלוקח **כל** קובץ אודיו או וידאו ומחזיר את התוכן שלו כטקסט, באמצעות
OpenAI Whisper. חולץ מהליבה של פייפליין תמלול השיעורים — רק חלק התמלול, בלי
שום דבר ספציפי לשיעורים (בלי Google Drive, בלי מספור שיעורים, בלי סיכום).

## 🎯 מה הסקיל מבצע
1. מקבל נתיב לקובץ אודיו/וידאו.
2. ממיר ומכווץ את פס הקול ב-FFmpeg (מונו 16kHz) — הפורמט הכי טוב וקטן לתמלול.
3. אם הקובץ גדול מתקרת Whisper (25MB) — חותך אותו לחלקים אוטומטית.
4. מתמלל כל חלק ב-Whisper ומחבר לתמלול אחד.
5. מדפיס את התמלול (ואם התבקש `-o` — גם שומר לקובץ).

## 📥 קלט / 📤 פלט
- **קלט:** קובץ אודיו או וידאו (m4a, mp3, wav, mp4, mov, ...).
- **פלט:** טקסט התמלול ל-stdout; אופציונלית נשמר לקובץ עם `-o`.

## 🗣️ איך מריצים
```
python transcribe_audio.py <קובץ> [-o פלט.txt] [--language he] [--env נתיב/.env]
```
דוגמאות:
```
python transcribe_audio.py meeting.m4a
python transcribe_audio.py interview.mp4 -o interview.txt --language he
```
- `--language` — קוד שפה (למשל `he`, `en`). בלי זה: זיהוי אוטומטי.
- `--env` — נתיב לקובץ .env אם המפתח לא בתיקייה הנוכחית.

## 🔧 דרישות (פעם אחת)
- **FFmpeg + ffprobe** מותקנים (Windows: `winget install --id Gyan.FFmpeg -e`).
- חבילות Python: `pip install openai python-dotenv`.
- **OPENAI_API_KEY** — בקובץ `.env` (בשורה `OPENAI_API_KEY=sk-...`) או במשתני הסביבה.

## ❌ מה הסקיל לא עושה
- לא מסכם ולא מנתח — רק תמלול גולמי. (סיכום = שלב נפרד, "מוח".)
- לא מוריד קבצים מ-Drive/ענן — מקבל קובץ מקומי שכבר קיים.
- לא מזהה דוברים (diarization) — תמלול רציף בלבד.

## 📝 לוג עדכונים
🔧 נוצר — חולץ מ-`transcribe_lesson.py` (פייפליין תמלול השיעורים) כליבה גנרית לשימוש חוזר.

## 🗣️ הוראות לקלוד — מאיפה להתחיל
כשמבקשים תמלול קובץ:
1. ודא ש-FFmpeg מותקן ושיש OPENAI_API_KEY (ב-.env או בסביבה).
2. הרץ `python transcribe_audio.py <קובץ>` — התמלול חוזר ב-stdout.
3. תמלול נכשל → בדוק את המפתח; "FFmpeg לא נמצא" → הפנה להתקנה למעלה.
4. קובץ ענק/ארוך → הסקיל חותך לבד; אם נתקע, ודא שיש מקום פנוי בדיסק.
