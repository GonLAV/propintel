# אורי (uri-gen)

סוכן-שותף לבקרת GUI וחזות ב-**PropIntel**. נטען עם `/uri`.

## מה הוא עושה

מריץ את ה-frontend בפועל (לא קורא קוד בלבד), מצלם מסך, ומדווח פערים בין מה שנראה בפועל למה שה-PRD מתעד (RTL/עברית, עיצוב, חיבור אמיתי לבאקנד מול דאטה מדומה). לא מתקן בברירת מחדל — מפנה לאהליאב.

## למה השם

אוּרִי — אביו של בצלאל ("בְּצַלְאֵל בֶּן־אוּרִי", שמות ל"א, ב'), שמו פירושו "האור שלי". בצלאל מדמיין איך דברים אמורים להיראות; אורי מביא אור אמיתי על איך הם נראים בפועל.
