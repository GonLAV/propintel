# Rebuild Plugin

מטרה: לארוז את תיקיית הסוכן הנוכחית לקובץ `.plugin` יחיד שאפשר להתקין, לגבות או לשלוח.

> הערה לסביבה: הקובץ הסופי נשמר בתוך ה-repo המחובר (`plugin-builds/`)
> כדי שאפשר יהיה לראות אותו ולגשת אליו ישירות ממערכת ההפעלה המקומית.

## שלב 1 — אימות

1. ודא שאתה נמצא בתוך תיקיית סוכן: חייב להיות `.claude-plugin/plugin.json`.
2. שלוף את שם הסוכן מתוך השדה `name` שב-`plugin.json` (זה יהיה שם הקובץ).
3. בדוק שהקבצים המרכזיים קיימים:
   - `.claude-plugin/plugin.json` (חובה)
   - `system-prompt.md`
   - `skills/`
   - `commands/`

## שלב 2 — בנייה (zip)

מתוך תיקיית הסוכן, ארוז את כל התוכן לקובץ זמני:

```bash
cd <agent-folder>
zip -r "/tmp/oholiav-gen.plugin" . -x "*.DS_Store"
```

## שלב 3 — העברה ליעד

העתק את הקובץ הסופי לתיקיית `plugin-builds/` בשורש הריפו (צור אם לא קיימת), ודווח גודל וקבצים שנכללו.
